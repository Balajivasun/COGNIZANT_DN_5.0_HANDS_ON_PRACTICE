# Git Cleanup Commands - Task 5

## Steps

1. Verify master status:
```bash
git status
```

2. List all branches:
```bash
git branch -a
```

3. Pull remote repository:
```bash
git pull origin master
```

4. Push pending commits (`Git-T03-HOL_002`):
```bash
git push origin master
```

5. Verify remote reflection on GitLab/GitHub interface.
